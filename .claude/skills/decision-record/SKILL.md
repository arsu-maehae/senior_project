# Decision record: $ARGUMENTS

Create docs/decisions/NNN-<short-name>.md (NNN = next number) with:

- **Title** and **date**, **status** (accepted / superseded by NNN)
- **Context** — the problem in 3–5 lines, with the evidence (event IDs, counts from log-check)
- **Options considered** — table: option · pros · cons · evidence
- **Decision** — one paragraph
- **Consequences** — what this makes easier / harder; limitations to state in the report
- **Kill criteria** — the measured result that would make us change it
- **Committee answer** — the 2–3 sentence answer (English and Thai) to "why did you choose this?"

Keep it under one page. Link the council verdict or research note if one exists.
