### 1.3 What the spec assumes that the data supports only partly
1. `target_linked_logon_id` is never set on type 3 logons: the "linked ID" part of ST-33 is untested.
2. 4688 command lines are missing in 28–44 % of rows; the command-line method depends on Sysmon 1.
3. Sysmon 10 has no session and its process joins a Sysmon 1 only partly.
4. 4647 carries its logon ID in `target_logon_id` only.
5. No type 10 logon and no 3389 connection in any development trial.
6. A boot epoch cannot rely on System 41.
7. Several §10 values are truncated, not rounded (50 ms, 1.715 s, 204 ms).

## 3. Council fact-check (adviser, decision 044) — three errors in the draft and the brief, corrected
1. "An 'after' side of 5 s loses s06-smb-1" is true only with a 30 s look-back. At 120 s the hop keeps its session through the earlier WinRM hop's evidence about 86 s back.
2. ST-46 as first written (any command of the session) was not the rule measured (only commands that name the target).
3. The 0.67 s / 0.47 s grouping margin holds for the 23 user endpoint → endpoint groups only; among endpoint → dc01 logons gaps run continuously through 2 s.
