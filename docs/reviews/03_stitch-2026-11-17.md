## Should fix: code bugs (fixed in `8ad41ff`, regression tests in `tests/unit/test_t77_review_fixes.py`)
- **ATK-23.** Evaluate compared the key's session uid with the whole `source_session_logon_uid` cell. That cell may hold several `;`-joined uids of one session (ST-05 copies, a second 4624 while open), so a correct session would score `wrong`. A cell holding the key uid is now the key session. No development result changes (all 11 compared cells hold one uid).
- **ATK-24 (a).** A Sysmon 1 agent uid of the key that is absent from `events_dedup` was skipped, so the keyed hop silently became a background hop (`expected_target_only` = 1). It is now a refusal; the message names the key hop and a count. A present uid with a NULL session is still skipped, as 051 item 4 reads.
- **ATK-27.** With an unterminated quote in a service image path, `binary_file_name` took the rest of the text, so argument text cut at its last `\` could reach `hop_artefacts.csv` `names`. Such a path is now read like an unquoted one (first token). Development outputs are byte-identical.
