file. The owner should know that the "never print command text" rule was broken once in a sub-agent transcript.

A script over the nine development DBs (all `command_line`, `commandline`, `parentcommandline`, `scriptblocktext`,
`contextinfo`, `payload`, `userdata` values) and the key `agent_command` fields compared every 12-character substring
with the spec, this review and the measurement JSON. The only overlaps were generic English phrases, JSON
punctuation, field names, public SigmaHQ rule text and target-side service names. Spec 03 §2 allows target-side
service names.
