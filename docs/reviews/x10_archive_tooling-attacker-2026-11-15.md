# Attacker review — archive and `retire-failed` design (T6c.5)

**Date:** 2026-11-15 · **Reviewed:** Task 3 of the T6c plan (`archive.py`: V1 archive, `retire-failed`), with Task 1 shadow guard · **Reviewer:** attacker agent (read-only) · **Dispositions:** the main session. Facts checked: `data/manifest.csv` is CRLF, no BOM, ends with `\r\n`; old rows have `source_path` `x10/S04/trial_01/…`; the manifest `path` column is identical for v1 and v2 rows.

Closing items 1–6 in the tests is a condition for starting the implementation of Task 3.

| # | Finding | Severity | Disposition (design change) |
|---|---|---|---|
| 1 | `retire-failed` can hit the retried (accepted) trial, an old v1 trial, t00, or an id of another scenario; a `source != x10` check passes on v1 reports (no `source` key) | blocking | Require `ingest.json["source"] == "x10_v2"` exactly; scenario in s01,s04,s05,s07 and trial in `t01`–`t10`; the failed attempt folder `data/incoming/x10_v2_failed/<S>/attempt_N` must exist and its file hashes must equal the manifest, `ingest.json` and disk hashes of the trial being retired; refuse if `data/incoming/x10_v2/<S>/trial_NN` holds the same files, if `docs/lab/test_set.csv` lists the id, or if the trial is neither a validator FAIL nor an ingest `error` |
| 2 | A stale `complete` ingest (failed attempt not retired) makes the re-run "complete, skipped"; the shadow guard passes because the failed attempt has v2 rows | blocking | Before skipping or ingesting (v2), compare the incoming pre-hash with the `files_copied` source sha of the existing `ingest.json`; a mismatch is a refusal "stale attempt: run retire-failed". `--force` never removes a DB in this case |
| 3 | Leftovers block or poison the retry: `out/ingest/x10_v2/<id>/`, `out/x10_validate_v2/<id>.json`, `data/trial_windows.csv` row, `out/gate`/`stitch`/`evaluate`/`answer_key` outputs; for V1 the surviving `out/ingest/x10/<id>/ingest.json` (status ok, DB gone) makes an unfiltered x10 batch re-ingest the old trial | blocking | `retire-failed` also moves the failed attempt's ingest and validator files into the archive (keeps the audit trail 052 needs) and refuses while any other per-trial path for the id is still live (reports it). V1: the archive report lists the archived ids; batch (source x10) treats them as "archived, skipped"; the v1 validator already skips a trial with no DB |
| 4 | A partially ingested failed trial (status `error`; raw + manifest rows, partial JSONL, `.sqlite3.tmp`/`-wal`/`-shm`, no DB) cannot be retired under "missing or unclassified file → refuse" | blocking | Missing and extra items are a per-preset policy: V1 strict, `retire-failed` tolerant; every missing or extra item is listed in the report |
| 5 | No fsync; the journal with source hashes is written last, so a crash after delete loses the hashes | blocking | Write the journal (source sha, size per file) first; fsync each destination and the archive manifest; delete only files the journal marks verified |
| 6 | `manifest.csv` rewrite: CRLF, BOM, no final newline (the existing `append_manifest` would glue the next row), concurrent batch append between read and replace, duplicate `path` rows | blocking | Byte-level split on `\r\n`, bytes written back; refuse BOM, refuse a file not ending in `\r\n` (also a guard in the v2 ingest before any append); lock file taken by both the archive and the batch; re-check that the on-disk bytes still start with the bytes read just before `os.replace`; duplicate `path`: move all rows or refuse |
| 7 | Resume gaps: crash between archive-manifest write and main-manifest rewrite (duplicate archive rows); source and dest both present with the row already moved; second `--execute` after a v2 ingest fires "archive too late"; report overwritten | should fix | Dedupe archive rows by path and sha; four per-file states (pending, copied, moved, done) incl. "both present, row moved"; read the archive manifest first so a second run is a no-op; append a run log instead of overwriting |
| 8 | Windows delete: `rmtree` would remove unlisted files and junctions; locked files (antivirus, open handle); `copy_one`'s `finally` unlink can mask the real error | should fix | Per-file `os.unlink` of journal-listed files, `rmdir` only when empty; refuse reparse points on source and dest; `PermissionError` is resumable with a bounded retry |
| 9 | SQLite sidecars (`-wal`, `-shm`, `.tmp*`) | should fix | Hash sidecars with the DB; refuse if `-wal`/`-shm` exist for V1 (DB in use); never open the DB |
| 10 | Selection: prefix collisions (`t1` vs `t10`), case-insensitive names, unsafe label/attempt arguments, `source_path` prefix cannot separate a failed v2 attempt from its retry | should fix | Regex `^t(0[1-9]|10)$` and path prefix with a trailing slash; casefold comparison; validate arguments (no `..`, no separators, attempt a positive int); a safe-dest guard for `data/processed` and `out/` too; the manifest filter is AND of scenario, trial, prefix; failed v2 attempts are matched by sha (item 1) |
| 11 | Success with a skipped hash; `verify` on an empty archive passes | should fix | The report counts verified/expected; the exit code is non-zero unless equal; V1 raw files compare against the original `ingest.json` sha; `verify` on an empty or half archive fails |
| 12 | Archived copy mistaken for live | note | Keep: no `.sqlite3` directly in `data/processed` or `data/processed/quarantine`; archive labels never match `s0?_t??`; `data/manifest_archive_*.csv` is a different name pattern from `manifest.csv`; test that `x10_validate.discover` and `answer_key.overlap.shared_trials` find nothing archived |
| 13 | Clock files and clock CSVs | note | `clock.txt` and `channel=clock` rows are allowed in the classification; `clock_offsets.csv` is bound to the DB hash, so DB and CSVs move together or the archive refuses |
| 14 | `.part` orphans | note | Reported, never counted as a destination, never moved as evidence |

Notes on dispositions: item 1's "validator verdict is not FAIL" is read as "not an accepted trial": the tool retires a trial only when its validator result has a FAIL or its ingest report has status `error`, and refuses an id listed in `docs/lab/test_set.csv`.
